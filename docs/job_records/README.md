# Job Record Templates (Schema v1.0)

**IMPORTANT DISCLOSURE:**  
The three JSON files in this directory (`template_job_01_hvac_condenser.json`, `template_job_02_basement_water_damage.json`, and `template_job_03_electrical_panel_hazard.json`) are **example structured templates** matching `job_record.schema.json` and `JobRecordJson` generated by `FieldCaptureRepository.buildStructuredJobJsonString()`.  

They are **NOT** claimed to be live walkthrough captures collected from physical Ray-Ban Meta hardware. Every capture entry carries `"evidenceSource": "MOCK_DEVICE_KIT_SCENE"` and `"isMockOrSample": true` until replaced by genuine on-device captures.

To generate live job records directly from the app:
1. Open the **Job & Est** tab in FieldCapture.
2. Tap **JSON** (`export_job_json_button`) to view the exported `JobRecordJson (v1.0)` payload queued for `POST v1/inspections/{jobId}/sync`.
